O fiscaldoo é feito para o **Odoo 20** (versão 20.0) e existe para as duas edições do Odoo: **Community** e **Enterprise**. Nas duas instalam-se os mesmos pacotes do fiscaldoo. No Enterprise juntam-se ainda os **pacotes de ligação ao Enterprise**, que põem o fiscaldoo a trabalhar com as aplicações do Enterprise.

## Versão do Odoo

- O código do fiscaldoo tem uma versão por versão do Odoo. A que existe hoje é a **20.0**, para o Odoo 20.
- Cada pacote do fiscaldoo tem um número que começa pela versão do Odoo, por exemplo `20.0.1.1.0`. Os dois primeiros números dizem para que Odoo é; os outros mudam a cada atualização do fiscaldoo.
- Esta documentação descreve o Odoo 20. No topo de cada artigo, a etiqueta da versão diz em que versão do Odoo o procedimento foi visto.

Se a empresa usa outra versão do Odoo, fale com o suporte do fiscaldoo antes de instalar: os pacotes da versão 20.0 não servem noutra versão do Odoo.

## Edições do Odoo

| Edição | O que se instala |
| --- | --- |
| Community | Os pacotes do fiscaldoo. |
| Enterprise | Os mesmos pacotes do fiscaldoo e os pacotes de ligação ao Enterprise (15). Onde o Enterprise já tem uma aplicação para a mesma tarefa, usa-se a do Enterprise. |

Os ecrãs desta documentação foram vistos numa base de dados «Odoo 20.0 (Community Edition)». Num Odoo Enterprise, alguns caminhos e ecrãs são os do Enterprise, como se diz em [O que muda no Enterprise](#o-que-muda-no-enterprise). Só alguns artigos têm já uma secção ou uma nota própria para o Enterprise; não há artigos repetidos por edição.

### O que quer dizer a etiqueta «Community e Enterprise»

No topo de cada artigo, incluindo este, há uma etiqueta com as edições do Odoo, por exemplo «Community e Enterprise». Essa etiqueta diz em que edições o procedimento do artigo serve. Um artigo com «Só Enterprise» trata de uma tarefa que só existe numa base Enterprise, como [passar os ativos do Enterprise para o fiscaldoo](/migration-toolkit/ativos-do-enterprise).

## O que muda no Enterprise

No Enterprise, usam-se primeiro as aplicações do Enterprise. O fiscaldoo deixa as suas de lado e junta-lhes o que é português. Cada linha corresponde a um ou mais pacotes de ligação, que se instalam sozinhos quando a base tem os dois lados: a aplicação do Enterprise e o pacote do fiscaldoo.

| Área | O que acontece no Enterprise |
| --- | --- |
| **Contabilidade** | Os anos fiscais do Enterprise e os do fiscaldoo ficam alinhados, e os menus repetidos do Enterprise ficam escondidos. A reconciliação bancária passa a ser a do Enterprise. Os diferimentos, as taxas de câmbio e os orçamentos são os do Enterprise: os do fiscaldoo não se instalam. |
| **Relatórios** | O balanço e a demonstração de resultados do plano português (SNC) aparecem nos relatórios do Enterprise, com os mesmos números do fiscaldoo. A declaração periódica de IVA, o SAF-T e os outros mapas portugueses continuam a ser os do fiscaldoo. |
| **Ativos** | Cada empresa usa os seus. Uma empresa portuguesa usa os **Ativos fixos** do fiscaldoo, com as taxas legais e os mapas fiscais. Uma empresa de outro país usa os ativos do Enterprise. Um pacote opcional passa para o fiscaldoo os ativos que uma empresa portuguesa já tinha no Enterprise: veja [Como migrar os ativos do Enterprise](/migration-toolkit/ativos-do-enterprise). |
| **Salários** | Cada empresa usa os seus. Uma empresa portuguesa processa os salários no fiscaldoo; uma empresa de outro país, nos salários do Enterprise. Os dois nunca se misturam na mesma empresa. |
| **Avenças** | As subscrições do Enterprise substituem as avenças do fiscaldoo. As avenças que já existiam passam uma vez para as subscrições, e as faturas que elas geram continuam certificadas. |
| **Cobranças** | Os lembretes de pagamento do Enterprise trabalham sobre as faturas certificadas. A única coisa que escrevem na fatura é a data do lembrete. Os avisos de cobrança do fiscaldoo ficam desligados. |
| **Assinaturas** | Há uma só aplicação de assinaturas, a do Enterprise, com o que só as assinaturas do fiscaldoo fazem lá dentro. Na ficha da empresa, no separador **Pessoas**, o administrador escolhe em **Pedir as confirmações pelo Sign** se o trabalhador confirma documentos, como o mapa de deslocações ou a declaração de presenças, pela assinatura do Enterprise. Vem desligado. |
| **Documentos** | Nos Documentos do Enterprise, quem trabalha só para uma empresa deixa de ver as pastas e os documentos das outras empresas da base. |
| **EDI e Peppol** | Os documentos Peppol que chegam aos Documentos do Enterprise são tratados como os outros documentos recebidos pelo fiscaldoo, com o histórico guardado. |
| **Copiloto** | O leitor de documentos do Copiloto convive com a leitura de faturas do Enterprise: numa fatura de fornecedor já lida pelo Copiloto, o botão de digitalizar do Enterprise não aparece. Um pacote opcional põe a configuração do Copiloto dentro da aplicação de inteligência artificial do Enterprise. |
| **Ecrã e perfis** | Cada perfil abre o seu ecrã inicial, como no Community. Os perfis do fiscaldoo ganham o acesso às aplicações do Enterprise instaladas, e os painéis leem os relatórios do Enterprise. |

A faturação certificada é a do fiscaldoo nas duas edições: as séries, a numeração, a assinatura dos documentos e o ficheiro SAF-T são os mesmos.

Nas empresas portuguesas, as taxas de câmbio automáticas e a leitura de faturas e de extratos pelos serviços online da Odoo começam desligadas. A empresa liga-as quando quiser. Ao ligar um destes serviços, ou a ligação ao banco pela Odoo, aparece um aviso de que os dados da empresa saem para os servidores da Odoo, e fica registado quem ligou e quando. <span className="fd-pending">Pendente de validação no ecrã: o aviso não se provocou, porque provocá-lo é ligar um serviço que envia dados para fora, e as bases de teste nunca o fazem.</span>

## Onde ver a versão e a edição do seu Odoo

Abra **Definições** e desça até ao fim da página, ao grupo **Sobre**. A primeira linha diz a versão e a edição. Só o administrador da base de dados tem a aplicação **Definições**.

Numa base Community, lê-se «Odoo 20.0 (Community Edition)»:

![Grupo Sobre das Definições com a linha Odoo 20.0 (Community Edition) assinalada](/images/getting-started/edicoes-e-versoes-suportadas/01-sobre-versao-e-edicao.png)

Numa base Enterprise, lê-se «Odoo 20.0+e (Enterprise Edition)»:

![Grupo Sobre das Definições com a linha Odoo 20.0+e (Enterprise Edition) assinalada](/images/getting-started/edicoes-e-versoes-suportadas/02-sobre-enterprise.png)

## O que precisa para instalar

Os requisitos, as pastas a copiar e a ordem de instalação nas duas edições estão em [Como instalar o fiscaldoo e que requisitos tem](/getting-started/requisitos-e-instalacao). Depois de instalado, os pacotes ligam-se nas Definições: [Como ativar a faturação e as aplicações do fiscaldoo](/getting-started/ativar-as-aplicacoes). Para passar uma base que já usa o fiscaldoo no Community para o Enterprise, veja [Como passar do Community para o Enterprise](/migration-toolkit/mudar-para-o-enterprise).
