## Sintoma

Ao guardar uma alteração, abre-se a janela **Sem acesso** e a alteração não fica gravada. Em **Contactos**, não aparecem os botões **Novo** nem **Ações**.

## Mensagem

Copiada do ecrã, ao alterar o telefone de um contacto e carregar em **Guardar**, com o perfil **Auditor / ROC**. O nome entre aspas muda com o tipo de registo:

> «Não tem permissão para alterar este registo de «*Contacto*». O seu perfil (Auditor) é só de leitura: consulta tudo e nunca cria, altera ou elimina nada.»

![Janela Sem acesso com a frase O seu perfil (Auditor) é só de leitura](/images/troubleshooting/perfil-auditor-so-de-leitura/01-auditor-so-de-leitura.png)

Nada foi alterado. Uma integração que usa um utilizador com este perfil recebe a mesma regra noutras palavras, obtidas por chamada direta, sem clique:

> «Não pode *criar* contactos: o seu perfil (Auditor) é só de leitura. O Auditor / ROC consulta os contactos mas nunca os cria, altera ou apaga, para que a pista de auditoria se mantenha fiável. Se um contacto precisa de mudar, peça a um utilizador com permissões de contabilidade ou vendas que o faça.»

> «Não tem permissão para *criar* «*Artigo*».
>
> O seu perfil (Auditor) é só de leitura: consulta tudo e nunca cria, altera ou elimina nada.»

## Causas verificadas

O utilizador tem o perfil **Auditor / ROC**. Este perfil serve para consultar os dados sem os poder mudar, para que o que o auditor viu continue a ser o que lá está. 
Os campos de uma ficha podem parecer editáveis. A recusa só aparece ao guardar.

## O que confirmar

1. Quem é o utilizador. A frase diz o perfil.
2. Se a pessoa é mesmo auditor ou se recebeu este perfil por engano: **Definições › Utilizadores e empresas › Utilizadores**, abra o utilizador, separador **Perfil**.

## Como resolver

- **É auditor:** a mensagem está certa. Saia da ficha sem guardar. Se um dado está errado, peça a correção a quem trata desse dado.
- **Precisa de outro perfil:** um **Administrador** muda-o no separador **Perfil** do utilizador, como em [Como dar a cada utilizador o perfil certo](/administration/perfis-e-permissoes).
- **É para reunir os documentos de uma auditoria:** veja [Como preparar o pacote para o auditor](/accounting-pt/pacote-do-auditor).

## Resultado esperado

Com outro perfil, a alteração guarda-se. Com o perfil de auditor, a consulta continua a funcionar.

## Quando contactar o suporte

- O utilizador não tem o perfil **Auditor / ROC** e a frase aparece.

Para outras recusas de perfil, veja [Não tenho permissão para fazer esta operação](/troubleshooting/sem-permissao).
