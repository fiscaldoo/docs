## Para que serve?

A lista de go-live junta num ecrã o que deve estar feito antes de a empresa emitir documentos a sério. Cada linha está **Feito** ou **A fazer**. A lista só mostra: não corrige nada.

## Quando utilizar?

- Na véspera de arrancar com uma empresa nova.
- Depois de uma migração, para ver o que ficou por limpar.
- Não use a lista em lugar do [guia de primeira configuração](/getting-started/configurar-uma-empresa-nova).

## Onde encontrar?

**Definições › Utilizadores e empresas › Lista de go-live**.

## Antes de começar

Entre como administrador do sistema. Feito a 21 de novembro de 2026, numa base de demonstração, com a **Empresa Demonstração, Lda** escolhida no canto superior direito.

## Como utilizar

<StepByStep>

1. Abra **Definições › Utilizadores e empresas › Lista de go-live**.
2. Leia cada linha. As **A fazer** são as que impedem o arranque.
   ![Lista de go-live com duas linhas A fazer e cinco Feito, uma delas «O fiscaldoo tem uma chave de assinatura ativa»](/images/administration/lista-de-go-live/01-lista.png)
3. Faça cada **A fazer** no sítio próprio e abra a lista outra vez para conferir.
4. Carregue em **Fechar**.

</StepByStep>

## Resultado esperado

Uma lista sem nenhuma linha **A fazer**. Na demonstração, a lista tem sete linhas:

- **Feito:** a moeda da empresa é o euro; a empresa já não é a empresa por omissão; o idioma Português (Portugal) está ativo; «O fiscaldoo tem uma chave de assinatura ativa.»; há uma série certificada ativa para esta empresa.
- **A fazer:** desinstalar os módulos de teste, de demonstração ou franceses (aqui, `l10n_pt_fiscaldoo_demo`) e arquivar ou eliminar os utilizadores de demonstração (aqui, dez).

## Notas importantes

- **Numa base de demonstração, as duas linhas ficam sempre «A fazer»**: é o esperado, e não se arquivam os utilizadores de uma demonstração.
- **A série conta só na empresa escolhida no canto superior direito.** Na demonstração, com a **Empresa Teste Portugal**, a linha da série passa a **A fazer**: «Esta empresa não tem nenhuma série certificada ativa: crie a série e comunique-a à Autoridade Tributária.»
- **A linha da chave pergunta ao fiscaldoo.** Já não há chaves de assinatura na instalação: quem assina é o fiscaldoo ([Como ligar a instalação ao fiscaldoo, que assina os documentos](/fiscal-core/chaves-de-assinatura)). A linha fica **Feito** («O fiscaldoo tem uma chave de assinatura ativa.») quando o fiscaldoo pode assinar. Quando não pode, fica **A fazer** com a mensagem do fiscaldoo. Numa base de testes o fiscaldoo é simulado e a linha está sempre **Feito**. Numa instalação sem a chave de API guardada (provou-se numa base de teste em que se desligou o simulador), a linha disse «Os documentos são assinados pelo fiscaldoo, mas a ligação não está configurada: preencha o endereço e a chave de API nas Definições. Nada foi assinado.»: guarde a chave de API nas Definições (o artigo acima tem os passos) e abra a lista outra vez.
- **A série conta como feita** se existir e estiver ativa. A lista não diz se foi comunicada à AT: veja [Como comunicar as faturas à AT](/fiscal-core/comunicar-faturas-a-at).

## Problemas frequentes

### A lista diz «A fazer» mas já fiz

- **Causa:** a lista foi aberta antes da alteração, ou a alteração não foi na empresa certa.
- **O que fazer:** feche a janela e abra-a de novo, e confirme a empresa no canto superior direito.
